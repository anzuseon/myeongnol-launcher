# 명선놀이터 시즌3 런처 v1.0.15

RAM 설정의 기본 최소값과 선택 가능한 하한을 6GB로 변경했습니다. 새 게임 설정은 최소 RAM 6GB로 시작하며, 최대 RAM도 최소 RAM 이상으로 맞춥니다.

기존에 6GB 미만으로 저장된 RAM 값은 설정을 불러올 때 6GB 이상으로 올립니다. 이미 더 높게 설정한 값과 Java 경로, JVM 옵션, 계정·게임 설정은 유지합니다. 서버가 6GB보다 높은 최소 RAM을 요구하면 그 값을 따릅니다.

최소·최대 선택 범위가 모두 6GB인 환경에서도 RAM 슬라이더가 정상 표시되도록 처리했습니다.
