# 명선놀이터 시즌3 런처 v1.0.9

런처 설치 파일·바로가기·창 아이콘을 명놀 아이콘으로 교체했습니다. 홈, 로그인, 환영 화면에는 공식 명선놀이터 로고를 표시하고, 로딩·설정 화면에도 명놀 아이콘을 적용했습니다.

배경은 명놀 배포 서버의 설정을 읽어 시작 시와 실행 중 5분마다 자동 갱신합니다. 창을 다시 활성화할 때도 확인합니다. 서버에서 배경을 바꾸면 런처 재배포 없이 반영됩니다.

받은 이미지를 검사하고 마지막 정상 배경을 저장합니다. 연결 실패 시 저장된 배경, 저장된 배경이 없으면 기본 전투 일러스트를 사용합니다. 배경 다운로드는 로그인·게임 실행을 기다리게 하지 않습니다.

기존 계정, 설정, 설치 경로와 게임 실행 기능을 유지합니다.
