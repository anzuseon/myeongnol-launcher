# 명선놀이터 시즌3 런처 v1.0.17

RAM 슬라이더의 마우스 좌표 계산 오류를 수정했습니다. 중첩된 설정 패널에서 드래그할 때 값이 튀거나 끝까지 이동하지 않는 문제를 해결했습니다.

바의 아무 위치나 클릭해 값을 선택할 수 있고, 손잡이 밖으로 드래그해도 최솟값·최댓값까지 움직입니다. 조작 영역을 넓히고 방향키·Home·End 키 조절을 지원합니다. 창 크기나 스크롤 위치가 달라도 같은 비율로 동작합니다.

선택 범위가 6GB 하나로 고정된 PC는 비활성 상태와 설명을 표시합니다. 최소 RAM 6GB 정책과 기존 배경·계정·게임 실행 설정은 유지합니다.
