# 명선놀이터 시즌3 런처 v1.0.10

런처를 왼쪽 메뉴와 반투명 카드 중심의 UI로 변경했습니다. 홈에 실제 계정 정보·서버 상태·게임 버전을 표시하고 초록색 게임 실행 버튼을 배치했습니다. 계정, 게임 설정, 런처 설정, 정보, 소식과 게임 폴더 열기를 연결했습니다.

슬로건·인사말·장식 문구를 제외했습니다. 기존 배경 이미지와 서버 배경 설정, 배경 자동 갱신 기능은 유지합니다.

로그인하지 않아도 홈을 볼 수 있으며 게임 실행 시 로그인으로 안내합니다. 빠른 메뉴 이동 시 화면 전환이 겹치지 않도록 처리했습니다. 기본 창은 1440×810, 최소 창은 1024×640입니다.

기존 계정·설정·게임 설치 경로와 모드팩 설치·실행 기능을 유지합니다.
