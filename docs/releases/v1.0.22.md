명선놀이터 시즌3 런처 1.0.22

- Minecraft 26.3 테스트 프로필과 최신 명놀 서버 선택 로고를 추가했습니다. 기존 26.2 프로필도 사용할 수 있습니다.
- 업데이트 관리자에서 수정한 서버 이름·설명·주소·로고·모드의 로컬 미리보기를 지원합니다.
- 게임 기본 설정을 첫 실행만, 설정 변경 시 한 번, 매 실행 중 선택해 적용할 수 있습니다. 지정한 항목만 변경하고 기존 options.txt는 변경 전 백업합니다.
- 공개된 서버 정보가 설치 파일에 포함된 이전 정보로 덮이지 않도록 개선했습니다.
- 자동 업데이트와 새 설치 모두 아래 설치 파일을 사용합니다.

첨부된 모드 JAR 두 개는 소스에서 런처를 다시 빌드할 때 사용하는 고정 버전 자산입니다. 일반 사용자는 설치 파일만 받으면 됩니다.
